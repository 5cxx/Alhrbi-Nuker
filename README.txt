          Alhrbi Tool - Readme

Requirements (المتطلبات):

* Windows 10 / 11
* Python 3.10 - 3.11 (Recommended)
* discord.py (latest)
* colorama
* aiohttp


How to Install (طريقة التثبيت):

1. Install Python 3.10 or 3.11:
   https://python.org/downloads
   NOTE: Python 3.12+ may cause issues with discord.py (Recommended: Python 3.10)

2. Run setup.bat to install required packages:
   Just double-click setup.bat

   Or install manually via CMD:
   pip install discord.py
   pip install colorama
   pip install aiohttp

3. Run the tool:
   Double-click run.bat
   Or type in CMD: python "Alhrbi Nuker.py"


How to Use (طريقة الاستخدام):

1. Enter your Bot Token.
2. Select the Server (Guild) from the list.
3. Select an option from the main menu.
4. Type alhrbi to trigger the hidden option.


Menu Options (خيارات القائمة):

[1] Delete All Channels
[2] Delete All Roles
[3] Mass Create Channels
[4] Mass Rename Channels (Random)
[5] Mass Rename Channels (Custom Name)
[6] Mass Send Messages to All Channels
[7] Ban All Members
[8] Kick All Members
[9] NUKE SERVER
[0] Exit
alhrbi - Hidden Art / Custom Command


Important Notes (ملاحظات هامة):

- The bot MUST have Administrator permissions in the target server.
- Make sure all Privileged Gate Intents are enabled in the Discord Developer Portal for your bot.
- Press ENTER during heavy operations to cancel the task.
- If you encounter "ModuleNotFoundError: No module named 'cgi'":
  * Install Python 3.10 or 3.11 instead of Python 3.12+.
  * Or update discord.py using: pip install discord.py --upgrade
