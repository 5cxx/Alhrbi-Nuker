=========================================
    Alhrbi Tool - Readme
=========================================

How to install:

1. Install Python 3.8 or higher
   https://python.org/downloads

2. Run setup.bat to install required packages
   Just double click setup.bat

   Or install manually:
   pip install discord.py
   pip install colorama
   pip install aiohttp

3. Run the tool:
   Double click run.bat
   Or type in cmd:
   python tool.py


Requirements:

- Python 3.8+
- discord.py
- colorama
- aiohttp
- Windows 10/11


How to use:

1. Enter your bot token or user token
2. Enter the guild ID (server ID)
3. Choose bot token or user token
4. Select an option from the menu
5. Type alhrbi for full nuke


Options:

1. Delete All Channels
2. Delete All Roles
3. Create Channels
4. Rename All Channels (Random)
5. Rename Channels (Custom Names)
6. Send Message to All Channels
7. Ban All Members
8. Kick All Members
9. Exit
alhrbi - Full Nuke (delete everything, ban all, create new channels)


Notes:

- User token may get your account banned
- Use bot token for safety
- Bot needs admin permissions
- Press ENTER to cancel any operation
